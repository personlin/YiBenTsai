# YiBenTsai
追思蔡義本教授

## Build Information

This website is built using:
- **Hugo**: v0.140.2 (Extended)
- **Node.js**: v20.19.0 LTS
- **R blogdown**: For content management

## Netlify Deployment

The site is configured to deploy on Netlify with the following settings specified in `netlify.toml`:
- Hugo version: 0.140.2
- Node.js version: 20.19.0
- Build command: `hugo --gc --minify`
- Publish directory: `public/`

## Local Development

To build this site locally, you'll need:
1. Hugo Extended v0.140.2 or higher
2. Node.js v20.19.0 or higher
3. R with blogdown package

Build command: `hugo --gc --minify`
